# SoulSpace — Spiritual Wellness Web Application

> **“Pause. Breathe. Reflect.”**

SoulSpace is a minimalist, serene spiritual wellness web application designed for mindfulness and self-care. Built purely with **HTML5**, **CSS3**, and **Vanilla JavaScript** without any external frameworks.

---

## 🌸 Modules & Practices

### 1. Meditation (`soulspace-meditation`)
- **Files**: `meditation.html`, `meditation.css`, `meditation.js`
- **Features**:
  - Serene countdown meditation timer (2 min, 5 min, 10 min).
  - Ambient relaxing audio (with built-in 432Hz ambient drone fallback).
  - Synchronized gentle guidance prompts.
  - Post-practice mood tracker (Relaxed, Refreshed, Calm, Neutral).
  - Reflection notes with browser `localStorage` history.

### 2. Breathwork (`soulspace-breathwork`)
- **Files**: `breathwork.html`, `breathwork.css`, `breathwork.js`
- **Features**:
  - Box Breathing (4-4-4 pattern: Inhale, Hold, Exhale).
  - Slow Breathing (5-0-5 pattern: Inhale, Exhale).
  - Smooth animated breathing visualizer rings with exact phase timing.
  - Audio cues with volume controls.
  - Cycle counters and completion reflections.

### 3. Yoga & Light Exercise (`soulspace-yoga`)
- **Files**: `yoga.html`, `yoga.css`, `yoga.js`
- **Features**:
  - Curated gentle movement routines (Desk Break, Gentle Yoga, Morning Stretch, Back Relaxation).
  - Step-by-step guided routine with pose illustrations and countdown timers.
  - Curated video links.
  - Post-practice reflection journal stored in `localStorage`.

## 🎨 Visual Identity & Design System
- **Background**: Warm Ivory (`#FAF7F2`)
- **Primary Color**: Sage Green (`#557158`)
- **Accent Color**: Soft Lavender (`#EEEAF4`)
- **Typography**: Cormorant Garamond (Serif) & Plus Jakarta Sans (Sans-serif)
- **Aesthetic**: Peaceful, minimal, elegant, and warm.

---

## 🚀 How to Run
Simply open any of the HTML files in a web browser:
- `soulspace-meditation/meditation.html`
- `soulspace-breathwork/breathwork.html`
- `soulspace-yoga/yoga.html`
*(or open `index.html` to browse all practices from the central hub)*.
